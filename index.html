01 — EVENT-DRIVEN AI / DATA SYSTEMS

ReRoute AI

Autonomous Travel-Disruption Concierge

An event-driven multi-agent AI system that ingests live status events at scale, generates real-time risk scores, and autonomously executes policy-bounded recovery actions.

  • Designed a four-stage pipeline: Detect → Decide → Act → Notify, built to run on continuous, high-volume event streams.
  • Built missed-connection probability scoring from live flight-status events — the same class of problem as risk scoring from live vehicle telemetry.
  • Implemented policy-bounded alternative ranking using cost, cabin and layover constraints.
  • Designed atomic flight + hotel execution with two-phase commit and rollback.
  • Used an event-driven architecture with an append-only audit trail for traceability.
  • Benchmarked detection, execution and notification performance under load.
Node.js React Agentic AI Event Driven REST APIs Real-Time Scoring
02 — MACHINE LEARNING

PhysioAgency

Wearable Stress Detection for Supply Chain Resilience

A machine learning pipeline for detecting physiological stress using multi-signal wearable sensor data.

  • Processed six physiological signals: EDA, HRV, BVP, TEMP, ACC and IBI.
  • Used NeuroKit2 for SCR peak detection and HRV feature extraction including RMSSD and SDNN.
  • Built preprocessing and feature engineering pipelines over 60-second sliding windows.
  • Evaluated ANN, LSTM, TCN and Random Forest models.
  • Random Forest achieved a 93% F1-score.
Python TensorFlow Scikit-Learn NeuroKit2 LSTM TCN Random Forest
03 — DEEP LEARNING

RDLINet

Lightweight Respiratory Disease Classification

Lightweight deep learning system for multi-class respiratory disease classification from lung sound data.

  • Replicated a lightweight Inception-based architecture.
  • Achieved 96.02% accuracy across seven disease categories.
  • Used only 12,942 trainable parameters.
  • Integrated signal preprocessing and mel-spectrogram feature extraction.
  • Applied depthwise separable convolutions to reduce computational cost.
  • Deployed and benchmarked the model on Raspberry Pi 4.
Python Deep Learning TensorFlow CNN Audio ML Raspberry Pi
